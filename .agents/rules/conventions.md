# Code Conventions

# Git: Conventional Commits

- **Language: English.**
- Format: `<type>(<scope>): <short description>`
- Types: `feat`, `fix`, `test`, `refactor`, `docs`, `chore`, `style`, `perf`, `ci`, `revert`.
- Scopes: `measurements`, `targets`, `profiles`, `auth`, `api`, `db`, `ui`, `di`, `config`.
