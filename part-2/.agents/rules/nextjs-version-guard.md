# Next.js Version Guard

This project uses **Next.js 16.2.4 with React 19**.

Before writing any Next.js-specific code (routing, layouts, server/client components, image optimisation, font loading, metadata API), read the relevant guide in:

```
node_modules/next/dist/docs/
```

APIs, file conventions, and rendering models may differ significantly from older versions you have seen. **Do not assume any pattern is still valid — verify first. Heed deprecation notices.**
